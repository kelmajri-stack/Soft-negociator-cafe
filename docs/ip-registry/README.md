# سجل الملكية الفكرية - IP Registry

*تاريخ النشر: 2026-05-22*
*الإصدار: 1.0*

## نظرة عامة

سجل الملكية الفكرية (IP Registry) هو قاعدة بيانات مركزية توثق جميع حقوق الملكية الفكرية المسجلة ضمن نظام Soft Negotiator Cafe.

## الهدف

- توثيق وحماية حقوق الملكية الفكرية
- توفير مرجعية موثوقة وشفافة
- تسهيل البحث والوصول إلى المعلومات
- منع التعارضات والنزاعات

## محتويات السجل

### 1. بيانات الملكية
```
- معرّف فريد (ID)
- نوع الملكية (براءة اختراع، علامة تجارية، حقوق النشر، إلخ)
- مالك الحق
- تاريخ التسجيل
- تاريخ انتهاء الحق
- الوصف التفصيلي
```

### 2. الحالة والتحديثات
- **مسودة** - قيد الإعداد
- **مفعّل** - حق فعال
- **معلق** - قيد المراجعة
- **منتهي** - انتهى صلاحيته
- **ملغى** - تم إلغاؤه

### 3. المرفقات
- الوثائق الداعمة
- شهادات الملكية
- براءات الاختراع الأصلية
- اتفاقيات الترخيص

## كيفية البحث

```bash
# البحث بالكلمات المفتاحية
query: "اسم الملكية"

# البحث بنوع الحق
type: patent | trademark | copyright

# البحث بمالك الحق
owner: "اسم المالك"

# البحث بالحالة
status: active | pending | expired
```
